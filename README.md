# svelte-stash Demo

Demo of the svelte-stash state management utility.

[![GitHub Repo](https://img.shields.io/badge/GitHub-svelte--stash-blue?&logo=github)](https://github.com/atif-c/svelte-stash)
[![npm Package](https://img.shields.io/npm/v/svelte-stash?logo=npm)](https://npmjs.com/package/svelte-stash)

## Installation

```bash
git clone https://github.com/atif-c/svelte-stash-demo
cd svelte-stash-demo
npm install
npm run dev
```
